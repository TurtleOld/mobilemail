# MobileMail

Термины пользовательских сценариев MobileMail.

## Language

**Предложение обновления**:
Закрываемая плашка с новой версией приложения, размером загрузки и кнопками «Обновить» и «Позже».
_Avoid_: обязательное обновление, системное уведомление об обновлении

**Отложенное обновление**:
Обновление, для которого пользователь нажал «Позже». Повторное автоматическое предложение допускается при новом запуске после завершения процесса приложения.

**Готовое обновление**:
Полностью скачанное обновление, ожидающее перехода к системной установке. Если скачивание закончилось в фоне, предложение установки появляется после возвращения пользователя в приложение и необходимой разблокировки.
